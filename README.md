# Kayla Portfolio – Cloud Engineer

A personal portfolio website built to showcase projects, technical skills, and professional profile, with a cloud-hosted full-stack architecture.

## Project Overview

This project is a full-stack personal portfolio consisting of a React frontend and a Node.js/Express backend. The application is deployed using Netlify and Vercel.

## Features

- Personal profile and introduction
- Technical skills showcase
- Featured projects
- Contact information
- Backend API health check
- Frontend and backend integration

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Cloud & DevOps
- Git and GitHub
- GitHub Actions
- Netlify
- Vercel

## Cloud Architecture

- Frontend is hosted on Netlify.
- Backend API is hosted on Vercel.
- GitHub is used for source code management.
- GitHub Actions is used for CI/CD workflow automation.
